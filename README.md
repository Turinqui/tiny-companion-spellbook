# Tiny Companion Spellbook

A phone-first searchable collection of parenting scripts, low-mana options, and repair tools for small-human chaos.

This repository contains the source for the Tiny Companion Spellbook web app.

## Deployment

This is a static site intended to deploy directly from the repository root on Netlify.

## Data

Spell cards are stored in the browser using local storage. Use the app's JSON export/import tools for backups and moving data between devices.
